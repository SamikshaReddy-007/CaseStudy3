# Implementation of Stack and Queue Operations Using Linked Lists

## 1. Project Description

This project implements Stack and Queue data structures using singly linked lists in Python. A stack follows the Last In, First Out (LIFO) principle, while a queue follows the First In, First Out (FIFO) principle.

The system allows users to perform basic operations such as push, pop, enqueue, dequeue, and display. Each element is stored in a dynamically allocated node containing data and a link to the next node.

This project demonstrates the practical use of linked lists in implementing linear data structures efficiently.

## 2. Objectives

- To understand stack and queue data structures.
- To implement stack operations using linked lists.
- To implement queue operations using linked lists.
- To understand dynamic memory allocation through linked nodes.
- To handle underflow conditions when a structure is empty.
- To analyze the time complexity of basic operations.

## 3. Problem Statement

Stacks and queues are fundamental linear data structures used in many computer applications. Implementing them using fixed-size arrays may require capacity management. Linked lists provide a dynamic alternative in which elements can be added or removed without specifying a fixed capacity in advance.

The objective is to develop a Python program that implements stack and queue operations using singly linked lists and demonstrates their LIFO and FIFO behavior.

## 4. Technologies Used

- **Programming Language:** Python
- **IDE:** Visual Studio Code

## 5. Features

- Push an element onto the stack.
- Pop an element from the stack.
- Display stack elements.
- Enqueue an element into the queue.
- Dequeue an element from the queue.
